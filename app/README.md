# Sudhi

Cognitive care companion app for dementia patients and their caregivers. Built with Expo Router + TypeScript, targeting Android, iOS, and web. See [../PLAN.md](../PLAN.md) for the full product and technical plan.

## Get started

```bash
npm install
npx expo start --web   # or --android / --ios
```

## Status

Implemented so far (local state only, no backend yet):

- Onboarding carousel
- Patient home screen
- Daily routine checklist
- Memory Game (card matching)
- Brain Exercise (pattern sequence)
- Remember Me (tile-swap picture puzzle)
- Progress tracking (static demo data)
- Caregiver Corner
- Chat placeholder (local canned replies, not a real AI backend)

Not yet built, per [../PLAN.md](../PLAN.md): rhythm activity, Supabase auth/sync/storage, the real AI Edge Function behind Social Mode, and caregiver content-configuration screens.
